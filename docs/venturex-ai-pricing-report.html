Bright Data: biaya masa depan, bukan biaya peluncuran

Tarif yang telah ditetapkan adalah Rp27.000 per 1.000 request, atau Rp27 per request. Bila Trend Radar live diaktifkan nanti, gunakan refresh manual serta kuota eksplisit—misalnya 1.000 request/bulan menambah Rp27.000 pada biaya operasi.

Kode saat ini memosisikan Bright Data sebagai integrasi opt-in dan katalog tren kurasi dapat berjalan tanpa provider tersebut. Ini membuat biaya live data benar-benar nol pada skenario peluncuran yang dipilih.

Implikasi arsitektur VPS tunggal

Spesifikasi VPS cukup untuk tahap awal dengan 25 pengguna bersamaan apabila koneksi database, memory Node.js, dan request AI dibatasi. Namun aplikasi dan database berada pada satu titik kegagalan; backup PostgreSQL terenkripsi di luar VPS adalah kebutuhan operasional, bukan fitur tambahan.

03 · biaya AI

gpt-6-luna adalah penggerak biaya utama

Peluncuran memakai 9Router dengan harga resmi gpt-6-luna pada jalur Standard: US$0,10 per 1 juta token input dan US$0,50 per 1 juta token output. Jalur Standard dipilih karena fitur AI merespons langsung tindakan pengguna.

Rumus transparan

Biaya generasi = ((token input × US$0,10) + (token output × US$0,50)) ÷ 1.000.000 × Rp18.052.

Semua endpoint AI perlu memakai batas token yang sama atau lebih kecil dari skenario konservatif. Tanpa batas token dan kuota atomik, harga pelanggan tidak dapat dijamin.

05 · guardrail dan tindak lanjut

Syarat sebelum menjual akses berbayar

Kuota atomik
Tolak generasi ke-11 dalam periode bulanan, termasuk ketika pengguna mengirim request paralel.
Telemetry biaya
Simpan user, fitur, model, input token, output token, status, dan biaya estimasi untuk setiap request AI.
Batas token
Jaga seluruh fitur AI pada atau di bawah 4.096 token input dan 6.144 token output per generasi.
Rate limit
Batasi per akun dan per IP untuk menjaga CPU VPS serta mengurangi penyalahgunaan kuota AI.
Backup off-server
Buat backup PostgreSQL terenkripsi, tetapkan retensi, dan lakukan uji restore sebelum payment diaktifkan.
Review 30 hari
Bandingkan biaya AI aktual dengan batas konservatif; tetapkan harga reguler atau revisi kuota berdasarkan data.

Keputusan operasional

  • Gunakan katalog tren kurasi pada peluncuran; Bright Data live hanya dibuka setelah hak penggunaan dan anggaran request disetujui.
  • Jangan menawarkan AI tanpa batas atau rollover kuota sebelum telemetry dan kapasitas VPS tervalidasi.
  • Pisahkan biaya backup, pajak, dan payment gateway pada revisi laporan berikutnya; ketiganya tidak boleh disembunyikan dalam asumsi biaya minimum.
Keputusan sekarang: mulai dengan Early Access Rp29.000/bulan, kuota 10 generasi AI, dan guardrail biaya wajib. Naikkan ke Rp39.000/bulan setelah data pemakaian selama 30 hari mendukung keputusan tersebut.

Catatan: Semua angka bersifat estimasi operasional pada 19 Oktober 2026. Kurs, harga penyedia, dan pola token dapat berubah. Laporan ini bukan proyeksi pendapatan maupun komitmen harga permanen.
