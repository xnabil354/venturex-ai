# Indonesia ADM1 boundaries used by Trend Radar

- Dataset: geoBoundaries `gbOpen`, Indonesia (`IDN`), ADM1, simplified GeoJSON.
- Pinned source commit: [`9469f09`](https://github.com/wmgeolab/geoBoundaries/tree/9469f09/releaseData/gbOpen/IDN/ADM1).
- Source asset: [`geoBoundaries-IDN-ADM1_simplified.geojson`](https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/IDN/ADM1/geoBoundaries-IDN-ADM1_simplified.geojson).
- Boundary vintage: 2017; the dataset contains 34 ADM1 features.
- Source attribution reported by geoBoundaries: OpenStreetMap and Wambacher.
- License reported in the Indonesia ADM1 metadata: Open Data Commons Open Database License 1.0 (ODbL).
- License text: <https://opendatacommons.org/licenses/odbl/1-0/>.
- Feature identifiers use the `shapeISO` property and are explicitly mapped in `src/trend/indonesia-region-boundaries.ts`.

The displayed file is the pinned simplified source GeoJSON. It is distributed with this attribution and license notice. The map is limited to the dataset's 34 features and does not imply coverage of later province subdivisions. SearchApi regions that lack a matching feature remain in the ranked table and are not drawn on the map.
